# ПОЙМАЙ БУДУЛАЯ

Сетевая хоррор-игра в догонялки для двух игроков — **Монстра** и **Выжившего** —
в заброшенной психиатрической лечебнице «Будулай». Играется через интернет из разных
городов, работает на компьютере и на iPhone (Safari).

---

## Быстрый старт (играем через интернет)

Локальной сети не нужно. Нужен только этот проект и `cloudflared`.

```bash
npm install
npm run online
```

В консоли появится **большая рамка с публичной ссылкой** вида
`https://что-то-там.trycloudflare.com` — просто **отправь её второму игроку
в мессенджере**. Он открывает ссылку у себя (на iPhone — в Safari), ты
открываешь её же у себя — и вы в одной лечебнице.

> Ссылка живёт, пока работает `npm run online` на твоём компьютере.
> При каждом запуске ссылка новая.

### Если cloudflared не установлен

Установка в одну команду:

| ОС | Команда |
|----|---------|
| Windows | `winget install Cloudflare.cloudflared` |
| macOS | `brew install cloudflared` |
| Linux (deb) | `curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb -o cf.deb && sudo dpkg -i cf.deb` |

После установки **перезапусти терминал** и снова `npm run online`.
Регистрация в Cloudflare не нужна, это бесплатно.

### Запасной вариант — ngrok

1. Скачай с [ngrok.com/download](https://ngrok.com/download) (нужна бесплатная регистрация).
2. Запусти сервер игры: `npm start`
3. В другом терминале: `ngrok http 3000`
4. Отправь второму игроку ссылку `https://....ngrok-free.app` из колонки Forwarding.

## Вариант 2 — постоянная ссылка (Render/Railway)

Чтобы играть, **не держа компьютер включённым**, задеплой игру в облако.

### Render (бесплатно)

1. Залей проект на GitHub.
2. На [render.com](https://render.com): **New → Web Service**, выбери репозиторий.
3. Настройки: Build Command `npm install`, Start Command `npm start`,
   инстанс Free. Больше ничего менять не надо (порт игра берёт из `PORT` сама).
4. Через пару минут получишь постоянную ссылку `https://твоё-имя.onrender.com` —
   её можно сохранить в закладки и играть в любой момент.

> На бесплатном тарифе Render сервер «засыпает» после 15 минут тишины —
> первый вход может грузиться ~30 секунд. Дальше всё быстро.

### Railway

1. На [railway.app](https://railway.app): **New Project → Deploy from GitHub repo**.
2. Railway сам определит Node.js и запустит `npm start`.
3. В настройках сервиса нажми **Generate Domain** — это и есть постоянная ссылка.

## Как играть

| | Монстр (Охотник) | Выживший |
|---|---|---|
| Цель | Поймать за 3 минуты | Продержаться 3 минуты |
| Зрение | Красное «тёмное зрение», шире обычного, но **жертву не видит** — только её светящиеся следы, тающие за 5 секунд | Узкий конус фонарика; вне луча — тьма |
| Слух | Слышит дыхание жертвы вблизи | Сердцебиение ускоряется, когда Монстр ближе |
| Скорость | Чуть быстрее шага жертвы, без спринта | Спринт с выносливостью |
| Особое | Проверяет укрытия (мгновенная поимка, если там кто-то есть) | Прячется в шкафах, под кроватями, в камерах морга — в укрытии следов нет |

- Первые **10 секунд** раунда Монстр заморожен — Выживший убегает.
- Поимка — очко Монстру, побег по таймеру — очко Выжившему.
- После каждого раунда роли меняются. **Матч — до 5 очков.**

### Одиночная тренировка

Второй игрок занят? В комнате ожидания нажми **«Позвать Санитара»** —
второй слот займёт бот. Он играет честно: как Монстр идёт по твоим следам,
слушает дыхание вблизи и проверяет шкафы там, где след оборвался; как
Жертва — убегает, петляет и прячется. Если позже захочет зайти живой
игрок — просто перезапусти сервер (или дождитесь конца матча и выйди).

### Своё лицо для существа

Положи **одну** фотографию (jpg / png / webp) в папку `public/monster/` —
она натянется прямо на лицо Будулая в игре: обесцветится под мертвенный
тон, а поверх лягут провалы глазниц, зашитый рот и пряди волос. Лучше
всего работает портрет анфас крупным планом. Перезапуск сервера не нужен.

### Свои скримеры

При поимке игра показывает случайную морду из четырёх встроенных
(«Бледный», «Ухмылка во тьме», «Глаз», «Медсестра») с рёвом и визгом.
Хочешь страшнее и личнее — положи **свои картинки** (jpg / png / webp / gif)
в папку `public/scares/`: они автоматически попадут в ротацию с двойным
весом и будут выскакивать на весь экран с красным стробом, глитчем и
тряской — и при поимке, и в случайных вспышках-«помехах». Перезапуск
сервера не нужен, достаточно обновить страницу.

### Управление (вид от первого лица)

**Компьютер:** W/S — вперёд/назад, A/D — шаг вбок, ←/→ — поворот,
**клик по экрану включает мышь** (поворот головы, Esc — отпустить),
Shift — спринт, E или пробел — спрятаться / проверить укрытие.

**iPhone / телефон:** палец на **левой** половине экрана — джойстик ходьбы
(вверх = вперёд, появляется там, где коснулся); **свайп по правой половине —
поворот головы**; справа крупные кнопки «БЕГ» и «✚» (взаимодействие).
Фонарик всегда светит туда, куда смотришь.

## Решение проблем

**«cloudflared не найден»** — установи его (таблица выше) и перезапусти
терминал, чтобы обновился PATH. Проверка: `cloudflared --version`.

**Ссылка открывается, но пишет 530 / Bad Gateway** — туннель ещё
поднимается: подожди 15–30 секунд и обнови страницу. Если не помогло —
останови (`Ctrl+C`) и снова `npm run online`. Если в консоли появилось
предупреждение «туннель НЕ ПОДКЛЮЧИЛСЯ» — твоя сеть блокирует исходящий
порт 7844 (бывает у корпоративных/общественных Wi-Fi и некоторых
провайдеров). Варианты: раздать интернет с телефона, взять ngrok
(он ходит через обычный 443 порт) или задеплоить на Render (вариант 2) —
для постоянной игры это в любом случае лучший путь.

**Звука нет на iPhone** — iOS запускает звук только после первого касания
экрана: просто тапни в любом месте (внизу висит подсказка «коснитесь экрана»).
Также проверь, что телефон не в беззвучном режиме — Safari уважает
переключатель Silent.

**Высокий пинг (в углу экрана)** — на 30–80 мс игра рассчитана и играется
мягко: позиции соперника интерполируются, поимка считается на сервере с
компенсацией задержки. Если пинг стабильно больше 150–200 мс: закрой
торренты/видеозвонки, подключись к Wi-Fi 5 ГГц или включи на телефоне LTE —
и лучше задеплой игру на Render (вариант 2): облачный сервер обычно даёт
более ровный канал, чем домашний туннель.

**Второй игрок видит «лечебница переполнена»** — в игре уже два игрока
(или чей-то «призрак» после обрыва связи держит слот до 60 секунд). Подожди
минуту или перезапусти сервер.

**Страницу случайно обновили посреди матча** — ничего страшного: игра
вернёт в тот же раунд автоматически (имя вводить заново не нужно).

## Устройство проекта

```
server/
  server.js      — HTTP + WebSocket, слоты игроков, переподключение
  game-logic.js  — авторитарная симуляция: физика, укрытия, поимка
                   с лаг-компенсацией, раунды, счёт
  map.js         — процедурная генерация лечебницы (коридоры, палаты,
                   операционная, котельная, морг, детское крыло)
public/
  js/network.js  — WebSocket (ws/wss автоматически), автопереподключение, пинг
  js/input.js    — клавиатура, мышь, сенсорный джойстик
  js/render.js   — рендер: тени от стен (рейкастинг), свет, туман,
                   скримеры, зерно, аберрация
  js/audio.js    — весь звук синтезируется через Web Audio API
  js/ui.js       — экраны, HUD, протоколы раундов
  js/main.js     — состояние, предсказание движения, интерполяция
scripts/
  online.js      — сервер + cloudflared, печатает публичную ссылку
tests/
  integration.js — матч двух ботов: погоня, укрытия, таймер, реконнект
```

Сервер авторитарен: клиенты отправляют только ввод, все позиции и поимки
считает сервер — рассинхрон и читы исключены. Снапшоты фильтруются по роли:
Монстру координаты жертвы **не отправляются вовсе**, только следы.
